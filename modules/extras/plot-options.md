# 剧情发展选项

- 本轮结束时间外交回 8 个选项，用于指导剧情接下来的发展。选项要有**全局视角（上帝视角）**，从当前上下文出发给出剧情下一步的可能走向。
- 8 个选项的风格要拉开，覆盖：普通推进 / 时间或场景跳跃 / 色情 / 淫秽重口 / 角色内在特质（美德或缺陷）的具象化 / 大幅跳过时间，剩下两个自行补足，避免风格重复。
- label 写选项类别（5 字以内）；content 写具体的一条描述，约 30 字，写成可直接送出的输入。
- 不要出现负面导向的选项，例如恐惧、绝望、死路。
