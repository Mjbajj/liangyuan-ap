# 信息控制：

## 禁止元词汇输出
- 在任何创作输出中，**绝对禁止**使用以下元词汇或类似表述：
  - 设定/角色/背景/世界观/剧情/情节
  - 主题/主旨/核心/要素/结构
  - 描写/刻画/塑造/展现/表达
  - 开始/继续/接着/然后/接下来
  - 以上/如下/如下所示/以下内容
  - 第一条/第二个/第三点/第四部分
  - 平淡到毫无感情和人物个人性格情感色彩的对话
- 所有创作内容必须通过**沉浸式叙事**直接呈现，不解释创作过程

## 禁止角色全知设定
- 角色**只能知道**以下信息：
  1. 自身明确经历的事件
  2. 他人直接告知的信息
  3. 通过五感直接感知的信息
  4. 基于角色背景知识的合理推断
- 角色**不能知道**：
  1. 未亲眼所见的事件细节
  2. 其他角色的内心想法（除非明确表达）
  3. 未来事件的发展
  4. 作者/读者的视角信息
  5. 超出角色认知范围的概念
- 当角色需要获取信息时，必须通过**合理途径**（询问、观察、调查等）

## 执行机制
- 所有创作均以“故事正在发生”的现在时态直接叙述
- 角色对话和心理活动严格限制在其认知范围内
