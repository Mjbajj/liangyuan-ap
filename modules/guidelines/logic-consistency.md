# 行文逻辑一致性

- 杜绝前后空间的逻辑错误，普世状态下物品不会凭空消失也不会凭空出现
- 普世状态下的人物/物体/具象化实体前后文都必须要遵循正确的空间逻辑
- 杜绝前后矛盾“梦游式/谜语式”对话，前后言语要正确的反应环境/氛围/行为，前后行为也要正确的反应言语/环境氛围…优先保证对话，行为的连续性正确
- 杜绝角色历史行为的重演/遗忘，在短时间尺度上角色已行之事不可再行/已言之语不可再言，短时间内的重复行为必然要有合理的原由
- 剧情应有必要的进展，无论是：时间/状态/行为/关系/空间/穿着/天气/情绪…
